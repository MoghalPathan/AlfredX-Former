# 🦇 AlfredX: Waynecore Assistant

> AI-powered desktop assistant inspired by JARVIS & Alfred Protocol

## 🎯 Features
- Voice activation (Winter Soldier Protocol)
- System control (apps, files, media)
- Computer vision
- Natural conversation with AI

## 🛠️ Tech Stack
- **Frontend:** PyQt5
- **Backend:** Python
- **Speech:** Vosk (offline) + Edge-TTS
- **AI:** Groq API (Llama 3)
- **Vision:** OpenCV + MediaPipe

## 📦 Installation
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/AlfredX-Waynecore-Assistant.git
cd AlfredX-Waynecore-Assistant

# Create virtual environment
python -m venv venv
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Download Vosk model (place in /model folder)
# https://alphacephei.com/vosk/models
```

## 🚀 Usage
```bash
python main.py
```
